# TextField

Etiketli tek satırlık giriş; sınavda açık uçlu cevap, girişte e-posta.

**Sen sağlarsın:** `label` (zorunlu say), isteğe bağlı `hint` ya da `error` (ikisi aynı anda değil), standart input özellikleri. Sayı, kesir veya formül cevaplarında `mono` aç.

- Hata metni ne yapılacağını söyler: "Sadeleştirmeyi unuttun." — "Geçersiz giriş" değil.
- Placeholder etiketin yerine geçmez; örnek göster ("Örn. 7/8").
