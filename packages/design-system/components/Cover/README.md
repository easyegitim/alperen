# Cover

Kapak bandı: sol altta "Öğrenmen" kelime markası ve slogan, sağda koddan üretilmiş blok illüstrasyon (mavi pelerin bloğu, altın, laci, easy moru; easy işaretinden gelen chevron deseni).

**Sen sağlarsın:** isteğe bağlı `title`, `tagline`.

- Renkler tema değişkenlerinden gelir (`fill-primary`, `fill-gold`, `fill-ink`, `fill-easy-purple`); iki temada ayrı dosya gerekmez. İllüstrasyon dekoratiftir (`aria-hidden`), dar ekranda gizlenir.
- Karşılama ve pazarlama yüzeyi içindir; uygulama içi sayfalarda kullanma. Sayfada `h1` bir kez: başlığı kapak taşıyorsa sayfada ikinci `h1` yazma.
