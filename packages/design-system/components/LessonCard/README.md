# LessonCard

Ders listesindeki tek ders: konu, başlık, süre ve ilerleme.

**Sen sağlarsın:** `title`, `subject` (BÜYÜK HARF, Türkçe İ ile: "MATEMATİK"), `meta` ("12 dk · 8 soru"), `progress` (0–100), `status` (`not-started`, `in-progress`, `done`), tıklanacaksa `href` ya da `onClick`. `ai` ders Öğrenmen tarafından kişiye özel hazırlandığında açılır: kart hologram ışıması (`shadow-ai`) ve açıklama satırı alır.

- 280px genişlik; ızgarada `space-6` aralıkla diz.
- Tamamlanan derste ilerleme altına döner; ayrıca kutlama ekleme.
