# ProgressBar

Ders, ünite veya haftalık hedef ilerlemesi.

**Sen sağlarsın:** `value` (0–`max`, varsayılan 100), `label`. Yüzde Türkçe biçimde başta gösterilir (`%62`); farklı bir birim için `valueText` ("5/5 ders").

- `primary` süren ilerleme; `gold` yalnızca tamamlanmış hedef ve ödül.
- Rayın içine metin yazma.
