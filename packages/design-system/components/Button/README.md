# Button

Tek düğme bileşeni; varsayılan `secondary`, **`primary` bir ekranda en fazla bir kez** — sayfanın asıl işi için ("Derse başla", "Cevabı gönder").

- `secondary`: ikincil ama görünür eylemler ("İpucu al", "Bir örnek göster").
- `quiet`: düşük öncelik ("Atla", "Sonra").
- `reward`: yalnızca ödül/kutlama anı ("Rozeti al"); `gold` dolgu, `on-gold` metin. Ders akışında kullanma.
- `size="lg"` mobilde tam genişlik CTA için `block` ile.

**Metin:** fiille başla, cümle düzeni, sen dili: "Derse başla", "Tekrar dene". Ünlem yok. `icon` dekoratiftir; anlamı metin taşır.
