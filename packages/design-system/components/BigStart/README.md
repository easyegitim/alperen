# BigStart

Bugün ekranının kahraman kartı: "Bugün sana önerim: Rasyonel sayılar · 8 soru · 12 dk" ve büyük **Başla**.

**Sen sağlarsın:** `title`, `meta` ("8 soru · 12 dk"), `onStart` ya da `href`; isteğe bağlı `eyebrow` (varsayılan "Bugün sana önerim"), `actionLabel` (varsayılan "Başla"), `headingLevel` (varsayılan 2).

- Ekrandaki tek birincil düğmedir (`primary`, `lg`, tam genişlik). Altındaki `SuggestionCard` kutuları ikincil kalır.
- Kart `section` olup eyebrow metniyle adlandırılır. Hologram ışıması (`shadow-ai`) yalnız bu kartta kullanılır.
