# Maskot

- `ogrenmen-maskot.webp` — Öğrenmen'in yapay zekâ öğretmeni: mavi pelerinli, kulaklıklı, gözlüklü, elinde kitap ve kalem tutan karakter; arkasında öğrenci hologramları. Şeffaf zemin. Karşılama ekranı, boş durumlar, ders sonu kutlaması ve `TutorMessage` avatarı (yüze kırpılmış) için.

Karakteri kırparken yüzü ve kulaklığı kesme. Üzerine metin yazma; metni yanına koy. Logo yerine kullanma.
