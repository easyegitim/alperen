# Logolar

- `easy-logo-mor-zemin.png` — easy'nin özgün logosu: mor (`easy-purple`) zemin üzerinde beyaz işaret. Kurumsal belgeler, sosyal medya avatarı ve easy imzası için. Değiştirmeden kullan.
- `easy-isaret-mor.png` — Özgün logodan zemini çıkarılarak elde edilen şeffaf işaret, mor mürekkep (`easy-purple`). Açık zeminlerde (`surface`, `surface-raised`) kullan.
- `easy-isaret-beyaz.png` — Aynı işaret, beyaz mürekkep. Koyu temada ve `navy`, `primary`, `easy-purple` dolguların üzerinde kullan.

İşareti yeniden çizme, döndürme, eğme veya renklendirme; yalnızca bu iki mürekkep vardır. Çevresinde en az işaret yüksekliğinin dörtte biri kadar boşluk bırak.
