# ogrenmen-pii (Python)

`packages/pii` modülünün Python yarısı. Ayrıntılı kurallar, vaka dosyası ve TS
eşleniği için üst dizindeki `packages/pii/README.md` dosyasına bakın.

```
python -m pip install -e /home/user/alperen/packages/pii/py[dev]
python -m pytest /home/user/alperen/packages/pii/py -q
python -m ogrenmen_pii.dump > /tmp/pii-py.json
```
